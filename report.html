1. Deskripsi Aplikasi & Tata Cara Penggunaan

SpendWise adalah aplikasi manajemen pengeluaran dan anggaran keuangan pribadi berbasis web yang dikembangkan khusus untuk berjalan di dalam ekosistem container (Docker/Podman). Aplikasi ini membantu pengguna dalam mencatat, mengelompokkan, memantau batas anggaran bulanan, serta menganalisis distribusi pengeluaran harian secara rinci dan visual.

Fitur Utama Aplikasi (CRUD & Analytics):

  • Manajemen Pengeluaran (Expense CRUD): Pengguna dapat menambah pengeluaran baru (Create), melihat tabel riwayat transaksi (Read), memperbarui data pengeluaran (Update), dan menghapus transaksi (Delete).
  • Manajemen Kategori (Category CRUD): Mengelompokkan transaksi ke dalam kategori seperti Makanan, Transportasi, Tagihan, Hiburan, dll. Pengguna dapat menambah, mengedit, dan menghapus kategori secara dinamis.
  • Alokasi Anggaran Bulanan (Monthly Budget): Menetapkan target limit anggaran bulanan dan menghitung sisa anggaran otomatis secara real-time.
  • Dashboard Visualisasi: Menampilkan ringkasan total pengeluaran, indikator sisa anggaran, peringatan penggunaan anggaran, dan chart distribusi pengeluaran.

Tata Cara Penggunaan Aplikasi:

  1. Buka Browser: Akses http://localhost pada browser setelah container berjalan.
  2. Navigasi Dashboard: Lihat ringkasan total pengeluaran, sisa anggaran, dan indikator persentase penggunaan anggaran bulanan.
  3. Menambah Kategori Baru: Buka menu Categories → Klik Add Category → Masukkan nama kategori → Simpan.
  4. Menambah Transaksi Pengeluaran: Buka menu Expenses → Klik Add Expense → Isi deskripsi, nominal (Rp), kategori, tanggal, dan metode pembayaran → Simpan.
  5. Mengedit & Menghapus Data: Pada tabel transaksi, gunakan tombol Edit untuk mengubah data atau Delete untuk menghapus catatan.
  6. Mengatur Anggaran Bulanan: Buka menu Budget → Masukkan batas nominal anggaran untuk bulan berjalan → Simpan.

2. Detail Arsitektur Aplikasi & Sumber Referensi

Aplikasi SpendWise mengadopsi arsitektur Multi-Tier Containerized Micro-services yang terdiri dari 3 layanan terpisah yang saling terhubung melalui Docker Network internal:

Layanan (Service) Teknologi / Base Image Fungsi Utama Port Container
Frontend React.js (Vite) + Nginx Alpine Antarmuka pengguna (SPA UI), routing visual, & Nginx Reverse Proxy ke Backend API. Port 80
Backend Node.js (Express.js) + Alpine Rest API server, logika bisnis CRUD, validasi data, & komunikasi ke MySQL Database. Port 5000
Database MySQL 8.0 Official Image Penyimpanan data relasional secara persisten (Expenses, Categories, Budgets). Port 3306

Sumber Referensi Kode / Referensi Aplikasi:

  • Backend API Framework: Express.js Documentation (https://expressjs.com/)
  • Database Driver: MySQL2 Promise API (node-mysql2)
  • Frontend Framework & Build Tool: React 18 & Vite (https://vitejs.dev/)
  • UI Styling & Icons: Tailwind CSS & Lucide React (lucide.dev)
  • Containerization Engine: Docker & Docker Compose Official Documentation (docs.docker.com)

3. Informasi File Pendukung & Konfigurasi Container

Untuk memenuhi kriteria penilaian penggunaan container (40 poin), berikut adalah file-file konfigurasi container yang digunakan dalam proyek ini:

A. File Dockerfile Backend (backend/Dockerfile)

# Base image Node.js Alpine
FROM node:20-alpine
WORKDIR /app

# Install dependencies
COPY package*.json ./
RUN npm ci --only=production

# Copy source code & Set Port
COPY . .
EXPOSE 5000

ENV NODE_ENV=production PORT=5000
CMD ["npm", "start"]

B. File Dockerfile Frontend Multi-Stage (frontend/Dockerfile)

# Stage 1: Build React SPA
FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

# Stage 2: Serve Nginx Web Server
FROM nginx:alpine
COPY nginx.conf /etc/nginx/conf.d/default.conf
COPY --from=builder /app/dist /usr/share/nginx/html
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]

C. Konfigurasi Orchestration (docker-compose.yml)

services:
  database:
    image: mysql:8.0
    container_name: spendwise-db
    environment:
      MYSQL_ROOT_PASSWORD: rootpassword
      MYSQL_DATABASE: spendwise
    ports:
      - "3306:3306"
    volumes:
      - db_data:/var/lib/mysql
      - ./database/init.sql:/docker-entrypoint-initdb.d/01-init.sql
    healthcheck:
      test: ["CMD", "mysqladmin", "ping", "-h", "localhost", "-u", "root", "-prootpassword"]
      interval: 5s
      timeout: 5s
      retries: 10

  backend:
    build: ./backend
    container_name: spendwise-backend
    ports:
      - "5000:5000"
    environment:
      DB_HOST: database
      DB_PORT: 3306
      DB_USER: root
      DB_PASSWORD: rootpassword
      DB_NAME: spendwise
    depends_on:
      database:
        condition: service_healthy

  frontend:
    build: ./frontend
    container_name: spendwise-frontend
    ports:
      - "80:80"
    depends_on:
      - backend

5. Tata Cara Eksekusi Container (Deployment Guide)

  1. Clone Repositori: git clone https://github.com/Michaelatj/SpendWise.git
  2. Masuk ke Direktori Proyek: cd SpendWise
  3. Build & Jalankan Container: docker compose up -d --build
  4. Cek Status Container: docker compose ps
  5. Akses Aplikasi Web: Buka http://localhost di web browser.
  6. Menghentikan Container: docker compose down
